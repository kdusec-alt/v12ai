# V1118 compact console and forward paper experiments

Search now precedes standby. Standby core, command summary and price ladder are compact; desktop defaults to the original full two-column panels with internal scrolling, and the deep report remains expandable. All existing analysis fields remain available. Compact layout aims to fit the main controls/summary/panels within common desktop viewports; mobile and full reports may scroll.

New `paper_lab_v1118.py` captures only newly logged predictions, freezes the available financial context and an exact matching Research Lab phenotype, and records OBSERVE or PENDING independently of the formal model. It never reconstructs older decisions or promotes a conditional HOLD to BUY. First observation per ticker/market/target session owns that day's experiment, preventing repeated queries from multiplying samples.

Simulation policy: only formal BUY with valid stop/target ladder; one normalized share, next-session open, 5 bps slippage per side, original invalidation stop and predicted next-day high as experimental take-profit, otherwise T+1 close. Gap beyond the original stop/target cancels the order. Both stop and target touched uses conservative stop-first. Taiwan single-price bars remain unverified. Fees are illustrative percentage assumptions (Taiwan 14.25 bps per side and 30 bps stock /10 bps ETF sell tax; US commission zero); broker minimum charges and full liquidity/auction execution are not modeled. This is a unit experiment, not a funded multi-position portfolio or a TradingView-equivalent strategy.

Settlement uses only existing verified local T+1 audit OHLC with the exact prediction ID, symbol and price date. No extra price requests, full-market scans, new timer or scheduler. Admin maintenance performs local reconciliation after existing auto audit. Each new logged query also reconciles already confirmed rows. A closed browser has no new unattended execution guarantee.

Financial learning: source/date and observed metrics are frozen before outcomes; verified revenue YoY groups collect descriptive next-session open-close and paper-return averages. ETF fundamentals, future dates, unverified growth are excluded. Fewer than 20 samples remains insufficient. Research phenotype is optional, same prediction and timestamp only; absence remains explicit. No changes to model weights or formal entry rules. This does not create an LLM earnings analyst or train a new model.

Storage: separate append-only experiment/outcome JSONL registered with the existing optional remote mirror/restore. UI reports remote configuration without claiming successful synchronization. Without configured remote persistence, data remains runtime-local. All hooks fail safely without blocking formal forecast rendering.

Validation: 28 unit checks, including price/date/no-lookahead guards, HOLD isolation, both-hit stop priority, gap cancellation, fees, finite OHLC, duplicate capture/settlement, frozen financial and research evidence, minimum sample gating, input ordering and original panel routing. Python compilation checked for changed modules. Live UI verification is tracked separately from test completion.
